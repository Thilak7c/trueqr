## 1. Product truths (don't get these wrong)
1. **Not registered ≠ blacklisted.** Unregistered → AMBER, "Pay anyway" allowed. Only confirmed → RED.
2. **Core check = "does this QR belong to the stall here?"** Registered stall ≤ 300 m + different QR → AMBER `qr_mismatch`.
3. **On-chain = fingerprint only:** `keccak256(qr text)` + stall name, photo URL, location, language. Never raw QR, never bank details.
4. Only the **relayer** (web server) can register/report. Only the **Sentinel** key can blacklist.
5. Blacklist = family taps "Not our QR", or ≥ 3 reports for same (stall, QR) in 1 h. Reversible.
6. **DemoPay is a mock** (fake balance, fake payment). Registry, reports, blacklist, Sentinel, Guardian are real on BSC testnet.
7. No crypto payments, no new stickers, no hawker wallets, no real wallet brands/logos.

## 5. Contract — `contracts/src/QRRegistry.sol` (^0.8.20)
```solidity
struct Stall { address registrar; bytes32 qrHash; string name; int32 latE6; int32 lngE6;
               string photoURI; string lang; uint64 registeredAt; bool active; }

uint256 public immutable deployBlock;            // = block.number in constructor
address public immutable agent;                  // Sentinel
mapping(address => bool)    public registrars;   // constructor only
uint256 public nextStallId = 1;
mapping(uint256 => Stall)   internal stalls;
mapping(bytes32 => uint256) public stallByQr;    // 0 = none
mapping(bytes32 => bool)    public blacklisted;

event StallRegistered(uint256 indexed id, bytes32 indexed qrHash, int32 latE6, int32 lngE6, string name);
event QrUpdated(uint256 indexed id, bytes32 oldHash, bytes32 newHash);
event MismatchReported(uint256 indexed stallId, bytes32 indexed scannedQrHash, address reporter);
event Blacklisted(bytes32 indexed qrHash, string reason);
event BlacklistRemoved(bytes32 indexed qrHash, string reason);

constructor(address agent_, address[] memory registrars_);
function registerStall(bytes32 qrHash, string calldata name, int32 latE6, int32 lngE6,
                       string calldata photoURI, string calldata lang) external returns (uint256); // onlyRegistrar; revert if hash registered or blacklisted
function updateQr(uint256 id, bytes32 newHash) external;            // only stall.registrar
function deactivate(uint256 id) external;                            // only stall.registrar
function reportMismatch(uint256 stallId, bytes32 scannedQrHash) external; // onlyRegistrar; stall must exist
function confirmBlacklist(bytes32 qrHash, string calldata reason) external; // onlyAgent
function removeBlacklist(bytes32 qrHash, string calldata reason) external;  // onlyAgent
function getStall(uint256 id) external view returns (Stall memory);
```
Tests: access control on every write · IDs start at 1 · duplicate hash reverts · blacklisted hash can't register · `updateQr` moves `stallByQr` · event args.
Deploy: `agent = SENTINEL address`, `registrars = [RELAYER address]`. Verify on BscScan. Copy ABI → `packages/core/src/abi.json`; address + deployBlock → `packages/core/src/address.ts`.

## 6. Core — `packages/core`
**emv.ts** `parseEmv(text) → { tags: Record<string,string>, payeeName?: string, isDynamic: boolean } | null`
Repeated `TT LL VALUE` (2-digit tag, 2-digit length). 59 = payee name, 60 = city, 01 = `11` static / `12` dynamic. `null` on any parse failure.

**fingerprint.ts** `qrHash(text) = keccak256(toUtf8Bytes(text.trim()))`
**geo.ts** `haversineM(a, b)` → metres.

**verify.ts** `verify({ qrPayload, lat?, lng? }, reader) → Verdict` where `reader` exposes `blacklisted(hash)`, `stallByQr(hash)`, `getStall(id)`, `listStalls()` (so tests use a fake). First match wins:

| # | Condition | status | reason | Pay button |
|---|---|---|---|---|
| 1 | `blacklisted[hash]` | red | `blacklisted` | hidden |
| 2 | EMV dynamic (`01=12`) | amber | `dynamic_qr` | "Pay anyway" |
| 3 | registered, location given, > 1,000 m from its stall | amber | `registered_elsewhere` (+ note `distance_m:<n>`) | "Pay anyway" |
| 4 | registered | green | `match` (+ note `distance_m:<n>`, or `location_not_checked` if no location) | Pay |
| 5 | not registered, location given, ≥ 1 active stall ≤ 300 m | amber | `qr_mismatch` (+ nearby, nearest first) | disabled |
| 6 | otherwise | amber | `unregistered` (+ note `location_not_checked` if no location) | "Pay anyway" |

Radii are wide on purpose: indoor phone GPS is often off by hundreds of metres. DemoPay drops any fix with accuracy worse than 500 m (sends no lat/lng → `location_not_checked`). `/wallet?debug=1` shows your lat/lng ± accuracy, the stall's lat/lng and the distance. `/wallet?venue=1` uses `NEXT_PUBLIC_VENUE_LAT/LNG` instead of GPS and shows a "Demo: venue location" badge.

`listStalls()` (chain reader) = `StallRegistered` logs from `deployBlock` + `getStall` for `active`, cached 15 s. Query logs in chunks ≤ 5,000 blocks. **Unit test every row.**

**reasons.ts** `message(reason, lang, {stall, payee}) → string` (EN + MS; Tamil falls back to EN):
| reason | EN | MS |
|---|---|---|
| `match` | This is {stall}. | Ini {stall}. |
| `qr_mismatch` | This QR doesn't pay {stall}. It pays {payee}. Don't pay. | QR ini bukan milik {stall}. Ia bayar kepada {payee}. Jangan bayar. |
| `blacklisted` | Reported scam QR. Do not pay. | QR penipuan yang dilaporkan. Jangan bayar. |
| `registered_elsewhere` | This QR belongs to {stall} at another location. | QR ini milik {stall} di lokasi lain. |
| `unregistered` | Not registered with TrueQR. It pays {payee}. | Tidak berdaftar dengan TrueQR. Ia bayar kepada {payee}. |
| `dynamic_qr` | TrueQR can't check this type of QR. | TrueQR tidak dapat menyemak QR jenis ini. |
Payee missing → "an unknown account" / "akaun yang tidak diketahui".

## 7. Web APIs (header `x-demo-token: DEMO_TOKEN` on all)
```
POST /api/verify { qrPayload, lat?, lng? }
→ { status, reason, notes[], message, payeeName|null, qrHash,
    stall: {id,name,photoURI,registeredAt}|null,
    nearby: [{id,name,photoURI,distanceM}], reportTx|null }
  on qr_mismatch: relayer reportMismatch(nearest.id, qrHash) — in-memory limit 1 per (stall,hash) per 10 min; don't await mining

POST /api/register multipart { qrPayload, name, lat, lng, lang, photo? }
→ { stallId, txHash, telegramLink: "https://t.me/<TELEGRAM_BOT_USERNAME>?start=s<id>" }
  reject if parseEmv null or dynamic or already registered; photo → Vercel Blob (if missing, photoURI = "")

GET /api/stalls → [{ id, name, photoURI, latE6, lngE6, active }]
```
The demo token is shipped to the client via a server-rendered page prop; it's a demo gate, not real auth.

## 8. Sentinel — `sentinel/`
State `sentinel/data/state.json`: `{ lastBlock, chats:{[stallId]:chatId}, alerted:{}, reports:{}, decisions:[] }`. Loop every 10 s.
1. Telegram `getUpdates` (offset tracked):
   - `/start s<id>` → save chat → reply "You'll get TrueQR alerts for {stall}."
   - callback `bl:<stallId>:<hash>` → `confirmBlacklist(hash, "Owner family confirmed not their QR at stall <id>")` → edit message "Blocked ✅ https://testnet.bscscan.com/tx/<tx>".
   - callback `ok:<stallId>:<hash>` → record "ignored" → edit message "Marked as yours."
2. New `MismatchReported` logs (first per stall+hash) → send to linked chat, inline keyboard `[Not our QR → bl:…] [It's ours → ok:…]`.
   Text (by stall lang):
   - EN: "⚠️ A QR that isn't yours was just scanned at {stall}. Please check for a sticker pasted over your QR."
   - MS: "⚠️ QR yang bukan milik anda baru diimbas di {stall}. Sila periksa jika ada pelekat ditampal di atas QR anda."
   - TA: use EN.
3. Backup rule: no reply and ≥ 3 reports for same (stall, hash) within 1 h → blacklist, reason "3 reports in 1h, no owner reply".
HTTP `:8787`: `GET /health → { ok, wallet, balance, lastBlock }`, `GET /status → { stalls, decisions }`.

2. Scanner: full-screen `html5-qrcode`, "Point at the stall's QR". Ask location once; continue if denied. Small "Paste QR text" link (dev + demo backup).

4. Result (top 45 % coloured block + icon + headline, white card below):
   - **Green** ✅ "Safe to pay" · photo (120 px circle, initials if none) · stall name · "Registered on TrueQR" · amount · **Pay**.
   - **Amber mismatch** ⚠️ "Not this stall's QR" · stall photo · "This QR doesn't pay **{stall}**. It pays **{payee}**." · Pay disabled · Scan again.

   - **Red** ⛔ "Do not pay" · "This QR was reported as a scam." · Scan again.
